2.3. Metodología de Integración (ETL)

El proceso ETL constituye la base del sistema de integración de datos. Permite
extraer información de múltiples fuentes, limpiarla y normalizarla para
cargarla en bases de datos NoSQL especializadas.

2.3.1. Extract (Extracción)
Se utilizan dos archivos CSV que simulan un escenario real de e-commerce:
- amazon.csv: 1,300 productos reales (catálogo)
- redis_cart_sim.csv: 500 eventos de compra (transacciones)
El módulo src/etl/extract.py implementa funciones que leen estos datos.

2.3.2. Transform (Transformación)
Se realiza limpieza y validación:
- Elimina registros incompletos (sin nombre o ID)
- Normaliza precios (remueve símbolos ₹ y separadores)
- Valida rangos (ratings 0-5, descuentos 0-100%)
- Completa valores faltantes con defaults apropiados
Resultado: ~900 productos válidos de 1,300 originales

2.3.3. Load (Carga)
Se persisten los datos en dos BD especializadas:
- MongoDB: Documentos JSON con catálogo (100 unidades iniciales por producto)
- Redis: Hashes con eventos agrupados por carrito (acceso sub-milisegundo)

2.3.4. Propósito General
Automatiza la ingestión, garantiza calidad, normaliza formatos, valida
reglas de negocio, y proporciona auditoría mediante CSV backup.
