═══════════════════════════════════════════════════════════════
🎯 PRINCIPIOS DE DISEÑO APLICADOS
═══════════════════════════════════════════════════════════════

✅ SRP (Single Responsibility Principle)
   Cada módulo tiene una sola responsabilidad clara

✅ Separation of Concerns
   ETL / Lógica de negocio / Visualización / Utilidades

✅ DRY (Don't Repeat Yourself)
   Helpers centralizados y reutilizables

✅ Modularidad
   Fácil extensión sin modificar código existente

✅ Testabilidad
   Estructura facilita tests unitarios

✅ Escalabilidad
   Preparado para crecer
